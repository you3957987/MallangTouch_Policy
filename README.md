# MallangTouch_Policy

말랑이 만지기 Android 앱의 공개 개인정보처리방침입니다.

- 공개 주소: https://you3957987.github.io/MallangTouch_Policy/
- 대상 패키지: `com.dottoline.mallangtouch`
- 개인정보 문의: `dottoline3957987@gmail.com`
- 시행일: 2026-10-29

`index.html`은 외부 폰트·스크립트·광고·분석 도구가 없는 정적 한국어 페이지입니다. `.nojekyll`로 별도 사이트 생성 없이 게시합니다.

## GitHub Pages

저장소의 Settings → Pages에서 Source를 **Deploy from a branch**, Branch를 **main**, 폴더를 **/(root)**로 설정합니다. Play Console에는 위 공개 웹페이지 주소를 입력합니다.

페이지는 로그인 없이 접근 가능해야 합니다. 앱의 설정 등에서도 동일한 URL에 접근하는 링크를 제공해야 합니다. 공개 페이지를 게시하는 작업만으로 게임 내 링크가 자동 추가되지는 않습니다.

## 유지 관리

게임 기능·SDK·문의 연락처·보관 및 삭제 정책이 바뀌면 본문과 최종 수정일을 갱신합니다. 공개 저장소에는 게임 코드·실제 사용자 저장 파일·문의 내역·API 키를 넣지 않습니다.

이 페이지는 현재 앱의 로컬 저장, Google Play Games 로그인·클라우드 저장, Google Play 구매 연동, 이메일 문의, 화면 캡처·공유, GitHub 우편 목록 갱신을 기준으로 작성했습니다. 데이터 보안 선언과 실제 출시 빌드도 같은 처리 내용에 맞춰 별도로 점검해야 합니다. 대상 연령 선택과 법정대리인 동의 요건은 개인정보처리방침 게시만으로 충족되는 것이 아닙니다.

## 데이터 삭제 안내 정정 (2026-10-29)

운영자가 이메일로 게임 데이터 삭제를 접수·대행한다는 약속을 제거했습니다. 현재 앱에는 해당 요청 기능과 접수·처리 절차가 없으며 90일 이내 자동 삭제도 하지 않습니다. 기기와 Google Play Games에서 사용자가 직접 삭제하는 안내와 일반 개인정보 문의 및 법령상 권리에 대한 연락처는 유지합니다.

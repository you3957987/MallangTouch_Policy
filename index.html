  • 이메일 서비스: 사용자가 보낸 문의는 사용자의 메일 서비스와 운영자의 Gmail을 통해 전달·보관됩니다. 문의에 비밀번호, 주민등록번호, 카드 번호 등 불필요한 민감정보를 넣지 마세요.

3. 다른 앱 위 표시와 화면 캡처

다른 앱 위 표시 권한은 사용자가 선택한 말랑이와 소품을 다른 앱 위에 보여주는 기능에 사용합니다. 이 표시 기능 자체를 위해 다른 앱의 메시지·입력 내용·연락처를 읽거나 수집하지 않습니다.

화면 캡처는 사용자가 촬영을 요청하고 Android의 화면 공유·촬영 동의 화면에서 허용한 경우에 수행합니다. 선택한 화면에 다른 앱의 내용이나 개인정보가 포함될 수 있으므로 촬영·저장·공유 전에 화면과 결과 이미지를 확인하세요. 화면 캡처 이미지와 사진 꾸미기 문구는 기기에서 처리합니다.

다른 앱 위 표시와 화면 캡처를 위해 기능에 맞는 포그라운드 서비스를 사용하고 시스템 알림을 표시합니다. 사용자는 기능을 종료하거나 Android 설정 및 시스템의 화면 공유 제어에서 관련 권한과 동작을 중단할 수 있습니다.

4. 보관 및 삭제 기준

  • 기기 내 저장: 게임 저장·설정·계정 연결 기록은 진행을 유지하는 동안 기기에 보관됩니다. Android에서 앱 저장 데이터를 삭제하면 해당 기기의 앱 저장 자료를 제거할 수 있습니다. 운영자는 기기 내 파일에 원격으로 접근해 삭제하지 않습니다.
  • 클라우드 저장: Google Play Games에 동기화한 자료는 기기 저장과 별도로 관리됩니다. 앱 삭제나 기기 데이터 삭제만으로 클라우드 자료까지 삭제되는 것은 아닙니다. 삭제 방법은 아래를 확인하세요.
  • 이미지: 촬영 결과는 처리 중 메모리와 공유용 캐시에 보관될 수 있습니다. 앱은 공유용 임시 파일을 만들 때 생성 후 하루가 지난 이전 공유 파일을 정리합니다. 정리 시점은 앱의 다음 공유 파일 생성 시점에 따라 달라집니다. 갤러리에 직접 저장했거나 외부 앱으로 보낸 이미지는 별도로 남으며 사용자가 해당 앱에서 삭제해야 합니다.
  • 문의 자료: 운영자는 문의 답변·후속 지원에 필요한 동안 문의 자료를 처리하며, 처리 목적이 달성되어 보관이 불필요해진 자료 또는 삭제 요청을 받은 자료는 삭제합니다. 법령상 보관 의무나 분쟁 대응 등 정당한 사유가 있는 경우 필요한 범위와 기간 동안 보관할 수 있습니다.
  • 외부 서비스 자료: Google·GitHub·이메일 서비스가 자체적으로 보관하는 진단·접속·결제 정보 등은 해당 서비스의 보관 및 삭제 기준을 따릅니다.
